# Text Analysis Script

## Overview
Analyzes a text file to count words, vowels, distinct words, sentences, paragraphs, and letter frequencies, along with word and sentence distributions.

## Usage
1. Place `war_and_peace.txt` in the same directory.
2. Run:
   ```sh
   python warandpeace.py
   ```
3. View results in the console.

## Notes
- Words are split by whitespace.
- Sentences end with `.`.
- Paragraphs are separated by `\n\n`.

A simple and efficient text analysis tool.
